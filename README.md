# Ketchup OS Online

Браузерная рабочая среда с оконным менеджером, виртуальной файловой системой и приложениями. Интерфейс на английском. Проект работает на статическом хостинге.

## Локальный запуск

Требуется Node.js 22.12 или новее и npm.

```sh
npm install
npm run dev
```

`npm run check` запускает TypeScript. `npm run build` проверяет типы и собирает сайт в `dist/`. `npm run preview` позволяет открыть production-сборку локально.

## Рабочий стол

- Start ищет приложения по названию и описанию. Значки на рабочем столе и панели задач запускают приложения одним нажатием.
- Перетаскивайте окно за заголовок и меняйте размеры за края. Двойное нажатие по заголовку переключает максимизацию. На узких экранах окна используют всю рабочую область.
- Правый клик по рабочему столу или кнопка с многоточием открывает параметры рабочего стола. Часы открывают Calendar, значок колокольчика показывает уведомления.
- В File Explorer выберите объект одним нажатием. Открыть его можно двойным нажатием, клавишей Enter или кнопкой внизу окна. F2 переименовывает объект, Delete открывает подтверждение удаления.
- Terminal работает с теми же виртуальными папками и файлами. Введите `help` для списка команд. В Notepad можно сохранить текст как виртуальный файл или скачать его.
- Browser открывает поиск и внешние сайты во вкладках браузера. Task Manager показывает открытые приложения и симулирует использование CPU и памяти.
- Settings меняет тему, оформление и обои. Gallery просматривает локальные фотографии и устанавливает их в качестве обоев. Calendar ведёт события. В Games доступны Signal Match и Caldera Tap.

| Клавиши | Действие |
| --- | --- |
| Alt + Shift + S | Start |
| Alt + Shift + W | Переключить окно |
| Alt + Shift + D | Показать или восстановить окна |
| Alt + Shift + X | Закрыть активное окно |
| Alt + Shift + T | Terminal |
| Esc | Закрыть системное меню |
| Ctrl / ⌘ + S | Сохранить текст в Notepad |

Настройки, открытые окна, файлы, заметки, уведомления, история, закладки, загруженные изображения, события и игровые рекорды хранятся в LocalStorage текущего профиля браузера и адреса сайта. Очистка данных сайта удалит этот рабочий стол.

## Публикация на GitHub Pages

1. Добавьте файлы проекта в GitHub-репозиторий с веткой `main` и отправьте изменения.
2. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в поле **Source**.
3. Запустите **Publish Ketchup OS to GitHub Pages** из вкладки Actions или сделайте новый push в `main`. Ссылка появится в окружении `github-pages`.

Vite использует относительный базовый путь, поэтому сборка поддерживает Pages в корне домена и в подпапке репозитория. [Документация Vite](https://vite.dev/guide/static-deploy#github-pages)

## Структура проекта

- `src/shell` — рабочий стол, Start, панель задач, уведомления и оконные рамки.
- `src/system` — оконный менеджер, файловая модель, настройки и сохранение данных.
- `src/apps` — отдельные приложения React.
- `src/styles` — стили оболочки и приложений поверх Tailwind CSS.
- `public/wallpapers` — обои проекта.
